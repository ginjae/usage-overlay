# Usage Overlay v1.2.0

Choose individual usage windows independently in Details and Overlay. This release also updates the initial configuration, simplifies reset timestamps, and aligns the Settings sidebar with the title bar.

## Choose which windows appear

- In **Settings → Details** or **Overlay**, choose **Selected Windows** for each provider, then switch **5-hour**, **Weekly**, and Claude's **Fable** window on or off individually. Additional window types reported by your account also appear as choices.
- Claude and Codex have separate selections, and Details and Overlay save their selections independently.
- Give each switch a unique identity across providers and panes. This fixes a bug in the local preview build where clicking Codex's 5-hour switch changed Claude's selection.
- **All Windows** and **Tightest Window** remain available; Details now supports these modes too. Existing single-window overlay preferences carry over to the corresponding selection.
- A selected window that is unavailable on your account no longer falls back to a hidden window. An empty selection displays **No windows selected**.

## Updated defaults

- The menu bar shows **All Windows** for both providers, with window labels hidden. **Logo Clock** remains the reset-time default.
- The overlay starts hidden. Use **Show Overlay** in the menu to enable it; its initial selection is **5-hour** and **Weekly** for each provider, with Fable off.
- Details continues to show all available windows by default. The refresh interval remains five minutes.
- New defaults apply to unset preferences and **Restore Defaults**. Existing saved choices remain intact; machine-specific paths and window positions are not distributed as defaults.

## Interface fixes and verification

- Reset timestamps in Details always show the abbreviated weekday and local time, including resets today or more than six days away.
- Align the Settings title-bar background with the sidebar divider, including after resizing the window.
- Update the README and details screenshot to match the current interface.
- Add regression coverage for window combinations, legacy preferences, persistence, unavailable windows, separate provider/pane identities, and the new defaults. The test suite now has 19 tests.
- Run the tests in GitHub before building and publishing releases, with enough fixture startup time for hosted macOS runners.

**Compatibility:** macOS 14 or later; universal Apple Silicon and Intel app.
