## Added

- Turn Claude and Codex on or off independently in **Settings → General → Providers**. Turning a provider off hides it throughout the app and pauses its usage checks.
- Select multiple usage windows for each provider in **Menu Bar**, **Details**, and **Overlay** settings. Right-click the **Windows** row to show **All** windows or just the **Tightest** one.

## Changed

- The new app icon brings half of each provider logo together on a glass panel.
- The local build script supports `--install` to replace and register an installed copy of Usage Overlay.
