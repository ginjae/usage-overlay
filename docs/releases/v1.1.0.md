## Added

- A Settings window with General, Menu Bar, Details, Overlay, and Colors panes, each with **Restore Defaults**.
- Clicking the menu bar item opens a details menu with each window's usage, reset time, and optional pace.
- **Logo Clock** and **Ring Clock** show the time until reset on the provider logo. Logo Clock is the default.
- More control over menu bar text, overlay columns and size, colors, and refresh intervals.

## Changed

- A new dark app icon.

## Fixed

- A CLI that ignores its timeout is stopped and cleaned up.
- Providers shown only in a hidden overlay are no longer queried.
