# Usage Overlay v1.1.0

Usage Overlay now has a dedicated Settings window, a detailed usage menu, reset clocks, and much broader control over the menu bar and overlay. This release also fixes CLI cleanup and unnecessary background queries.

Changes below are compared with **v1.0.3**, including the final state of the interface rather than intermediate development versions.

## Usage details from the menu bar

- Clicking the menu bar item opens a native macOS menu with Claude and Codex usage details, instead of the previous menu of configuration submenus.
- **Refresh Now** is first, followed by the update timestamp and a divider, then each provider's usage. Overlay visibility, position reset, Settings, and Quit remain available below.
- Each provider shows its plan, available rate-limit windows, percentages, bars, and reset information. Failed refreshes can show their explanation alongside the previously retained numbers.
- Reset information can include both a countdown and the actual local reset time, with a weekday or date when needed.
- Optional **Pace** estimates when a limit will run out or how much will remain at reset, based on usage and elapsed time in the current window. It is off by default and waits until at least 5% of the window has elapsed.
- Choose which providers appear, percent left or used, plan/bar/countdown/reset-time/pace/timestamp visibility, and menu width. Settings includes a preview of the details.

## A dedicated Settings window

- Settings are organized into **General**, **Menu Bar**, **Details**, **Overlay**, and **Colors** panes, with changes applied immediately.
- Each pane has its own **Restore Defaults** action.
- The resizable window remembers its frame and appears in the Dock and app switcher while open. Closing it returns the app to menu bar operation.
- Standard editing and window shortcuts work in the settings window, including copy/paste and closing the window. **⌘,** opens Settings.

## Menu bar appearance and reset clocks

- Choose usage windows independently for Claude and Codex. The previous shared window preference carries over until each provider is customized.
- **Logo Clock** and **Ring Clock** visualize time within a rate-limit window. Logo Clock is the new default for an unset preference and after restoring menu bar defaults.
- Choose each clock's window independently of its displayed percentages: first shown, tightest, 5-hour, weekly, or Claude's Fable weekly window. Missing selections fall back to the tightest available window; missing reset timing leaves a plain logo.
- Choose whether the lit portion follows the percentage direction, time left, or time gone. Adjust the unlit portion and ring thickness.
- Countdown remains available, with one- or two-unit precision; reset display can also be turned off.
- Window labels can be hidden, abbreviated, or full. The percent sign and hover tooltip can be toggled, and window separators can be a dot, slash, bar, or space.
- Customize font size and weight, fixed-width digits, logo size, and spacing between logos, values, windows, and providers.
- Menu bar colors can follow the system appearance, highlight only low remaining usage, or always use the configured usage-level colors.
- A live Preview shows the configuration on light and dark backgrounds, using sample values before the first usage response.
- Colored menu bar rendering resolves the appearance when drawing, so differently styled displays use appropriate foreground colors.

## Overlay customization

- Choose windows separately for each provider, including Claude's Fable window, and switch the overlay between percent left and percent used independently of the menu bar and details.
- Toggle the provider header, plan, window labels, bars, percentages, reset countdowns, and footer with its update timestamp and refresh button.
- Adjust width, text scale, bar thickness, background material, corner radius, and border. Backgrounds include four glass materials and a solid option.
- Lock the overlay position, choose whether it appears on every Space, and choose whether it stays above other windows. Existing visibility, opacity, click-through, dragging, and position reset controls are available in Settings.

## Colors and general preferences

- Customize the three usage-level colors and the thresholds for running low and almost out. Levels consistently use the amount remaining, even when displaying percent used.
- Customize Claude and Codex logo accents in the overlay, details, and settings, or let them follow the text color.
- Choose Claude-first or Codex-first ordering across the menu bar, details, and overlay.
- Add 2-minute, 15-minute, and 1-hour refresh choices to the previous 30-second, 1-minute, 5-minute, 10-minute, and 30-minute options. The default remains 5 minutes.
- Set CLI paths with text fields or a file picker, and see the executable actually being used or the fallback explanation. `~` is expanded, and a new valid custom path takes precedence over the cached executable immediately.
- Launch-at-login and update controls move into General. Update checking and downloading progress are shown in the window, and login-item errors are explained inline.

## Reliability and resource use

- A CLI that ignores termination after a timeout is forcibly stopped after a two-second grace period and reaped before the query returns. The same cleanup applies after a matching server response or an output limit.
- Replace detached stdout reader threads with nonblocking I/O and a deadline. Input and output can progress together, without leaving a reader blocked after a failed query.
- Limit captured stdout to 1 MiB. Line matching no longer retains every previous line, preserves UTF-8 characters split across reads, and accepts a final matching line without a newline.
- Stop querying providers enabled only in a hidden overlay. Showing the overlay again resumes the needed queries; providers used in the menu bar or details remain active.
- Check the expected Claude transcript path first and enumerate other project directories only when needed.
- Appearance-only settings changes do not restart usage scheduling or update checks. Views observe the shared settings directly instead of replacing the overlay's root view to apply each change.

## Existing settings and defaults

- Existing preference keys are retained, including overlay position, provider visibility, opacity, refresh interval, CLI paths, and update preferences.
- The previous Boolean window-label preference maps to short labels or none. The previous Boolean reset-countdown preference maps to Countdown or Off; saved string choices also remain intact.
- Logo Clock becomes the default only when no valid reset-display preference is saved, or after restoring defaults. An explicitly saved Off or Countdown choice is preserved.
- The new Details pane initially shows both providers. If you previously disabled a provider in the menu bar and overlay, disable it in **Settings → Details** as well to keep its CLI inactive.
- New clock-window controls default to the first displayed window. Provider ordering defaults to Claude first, the overlay still defaults to all available windows, and Pace remains off by default.

- The bundle script can use an optional separate image for small icon sizes.

**Compatibility:** macOS 14 or later, with a universal Apple Silicon/Intel app. The CLI-based quota readers, automatic updates, sleep/session suspension, and macOS 27 dragging support already existed in v1.0.3 and remain supported.
