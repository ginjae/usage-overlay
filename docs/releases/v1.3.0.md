# Usage Overlay v1.3.0

Settings now follows the layout of macOS System Settings, updates have a pane of their own, and the app has a new icon.

## Settings

- Search the sidebar to find a pane by any of its settings, such as **opacity** or **pace**.
- The top of the sidebar shows the app and its version. Each pane has an icon in the style of the new app icon and opens with a header describing what it controls.
- **Back** and **Forward** in the toolbar, or ⌘[ and ⌘], return to panes you visited.

## Updates

- **Settings → Updates** shows the installed version, whether a newer one is out, and what's new in it. Install it with **Update Now**.
- When a new version is available, a red badge and **Update Available** appear at the top of the Settings sidebar. Versions you skipped don't get a badge.
- **Check Now** shows its result in the pane instead of an alert. Opening the pane also checks for a new version, unless automatic checks are off.
- **Check for updates automatically** moved from General to Updates, so **Restore Defaults** in General no longer changes it.

## New icon

- A light tile with the orange chat bar and green code bar, placed on the standard macOS icon grid.

**Compatibility:** macOS 14 or later; universal Apple Silicon and Intel app.
