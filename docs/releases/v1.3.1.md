# Usage Overlay v1.3.1

Usage Overlay now uses the Liquid Glass look on macOS 26 and later, and the overlay can use Liquid Glass too.

## Liquid Glass

- On macOS 26 and later, the Settings window, its toolbar, and its controls use Liquid Glass. Earlier releases kept the older look even there, because the app was marked as built for macOS 14.
- As in System Settings, scrolling a pane draws a line under the toolbar, and the pane's name appears in the toolbar once its title scrolls up to it.

## Overlay

- **Settings → Overlay → Material** adds **Liquid Glass** on macOS 26 and later.
- The default background is now **Glass** instead of **Clear Glass**. A material you chose yourself is kept.

## README

- The README is reorganized into Overview, Quick start, and How it works, with new light and dark screenshots.
- It lists the exact `claude` and `codex` commands the app runs to read your usage. Neither sends a prompt to a model.

## Building from source

- `scripts/bundle.sh` now records the real macOS SDK version in the app. It warns when the SDK is older than macOS 26, since the app then keeps the older look.

**Compatibility:** macOS 14 or later; universal Apple Silicon and Intel app. Liquid Glass appears on macOS 26 and later.

**Full comparison:** https://github.com/ginjae/usage-overlay/compare/v1.3.0...v1.3.1
